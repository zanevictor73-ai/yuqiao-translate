# 让中文输入，直接进入英文或日文对话。

语桥现在可以选择 **英文 / 日文自动填入 Claude**：在中文输入窗写下想说的话，译文直接进入 Claude 草稿；你按回车发送后，回答会在右侧同步翻成中文。自己的中文原话也留在阅读窗，不必在翻译网站和聊天窗口之间搬运文字。

- **新增英文完整流程**：中文 → 英文自动填入 → 用户确认发送 → 英文回复同步回译。
- **日文同样保留**：在输入小窗切换语言，两种输出各用对应标点。
- **继续下一句更顺畅**：确认发送后清空中文草稿；阅读位置停在自己的问题附近，按自己的速度往下读。
- **无需大模型密钥**：使用普通在线机器翻译，需联网。Windows 听写入口继续可用。

选择 **Yuqiao-Claude-v1.10.0-windows.zip** 使用 Claude Windows 客户端适配；选择 **Yuqiao-General-v1.10.0-windows.zip** 使用独立即时翻译窗口。解压整个文件夹，再打开里面的程序。

公开版不包含自动启动、总控台或时区修改。Windows 11 x64 已验证；Windows 10 + .NET Framework 4.8 为目标环境，未单独完成实机验证。未声称支持 macOS、Claude 网页或其他 AI 的自动对话集成。界面主要为中文，入门文档中英文各一份。

验证：两版合计 **224 项自动检查**。2026-10-25 的真实 Claude 桌面操作还验证了英文与日文的完整对话流程。该实录使用共享翻译核心的自用构建；发布的公开构建单独执行全部自动检查。录音识别准确率不在这些自动检查的保证范围内。

# Type Chinese. Continue the conversation in English or Japanese.

Choose **English or Japanese automatic filling for Claude**. Write your message in Yuqiao's Chinese editor; the translation appears directly in Claude's draft. Send it yourself, then read the reply automatically translated into Chinese in the panel on the right—with your original Chinese question preserved.

- **New complete English flow:** Chinese → English draft → explicit user send → English reply translated into Chinese.
- **Japanese remains one switch away,** with language-appropriate punctuation.
- **A clean next turn:** the Chinese draft clears after the sent message is confirmed. The reader keeps your place instead of jumping to the end of a reply.
- **No LLM API key:** conventional online translation requires internet access. Windows voice typing remains available.

Download **Yuqiao-Claude-v1.10.0-windows.zip** for the Claude Windows desktop integration, or **Yuqiao-General-v1.10.0-windows.zip** for independent translation. Extract the entire ZIP before opening the executable.

The public editions exclude automatic startup, a control dashboard and time-zone changes. Verified on Windows 11 x64. Windows 10 with .NET Framework 4.8 is an intended, separately unverified target. No automatic integration is claimed for macOS, Claude on the web, or other AI apps. The UI is primarily Chinese; quick-start documentation is provided in both languages.

Validation: **224 automated checks** across both editions. Real Claude desktop demonstrations on October 25, 2026 additionally verified the complete English and Japanese conversation flows using the personal build with the same translation core. Public binaries are checked separately by the full suite. These checks do not guarantee speech recognition accuracy.
