# 语桥 · 开箱即用

这是 Windows 便携软件。请先解压整个文件夹，再双击其中的程序。需要 .NET Framework 4.8 和网络连接；当前实机验证为 Windows 11 x64。

## Claude 适配版：主要体验

打开 Yuqiao.Claude.exe，同时打开 Claude Windows 客户端。选择「Claude 客户端」，勾选自动翻译和自动填入，点击「悬浮模式」。

1. 在语桥输入中文，或选择中文输入法后点击「语音输入」。
2. 翻译完成后，日文自动填入 Claude 的对话框。请检查内容；你主动按 Enter 才发送。
3. 日文回复会在右侧自动译成中文。你的中文原话也会保留，回答更新不会强制滚到末尾。

确认发送成功后，本轮中文草稿会清空。正常填入后光标回到 Claude；需要修改中文时，点回语桥输入框。中文输入法选字不触发发送，Shift + Enter 换行。

输入、阅读、目录面板可分别显示和隐藏。目录、头像菜单与设置的中文辅助内容跟随可见界面；若切换会话后暂停，请点击「重新连接」。

## 通用即时翻译版

打开 Yuqiao.General.exe，选择中文→日文+英文，或日文/英文→中文。输入停顿约 0.6 秒后开始翻译，完成时间取决于网络。Enter 换行；「清空」开始下一段；「复制」复制相应译文。

通用版不会读取或填入其他应用。

## 语音与联网

「语音输入」调用 Windows + H。语音识别由系统处理，请在系统面板结束听写。语言、麦克风和在线语音设置会影响可用性。

无需大模型 API Key。普通机器翻译仍会把待翻译文字发送到 Microsoft / Google，Windows 听写也可能联网。不要将它理解为离线或完全不使用接口。

## 遇到问题

- 无法打开：确认使用 Windows，并已具备 .NET Framework 4.8。本项目没有数字签名；请只从项目发布页下载并核对 SHA256。
- 翻译失败：检查网络，稍后重试。公共翻译服务可能限流或更改接口。
- Claude 未连接：确认打开的是 Windows 客户端，聊天界面可见，再点击重新连接。
- 填入暂停：检查 Claude 是否有你手动写的草稿、当前对话是否改变；程序会保留不属于自己的文字。
- 网页、macOS 或其他 AI：尚未承诺这套自动对话适配；可以在 Windows 上使用通用版。

开源版不包含自动启动、后台启动监听、总控台或时区修改。
